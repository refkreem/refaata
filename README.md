# مقاول Pro — نظام حسابات وإدارة شركات تطوير المستشفيات

ملف واحد (`index.html`) يعمل على GitHub Pages، وقاعدة بيانات Firebase مشتركة بين المستخدمين.

## أولًا: التشغيل أول مرة
1. **Firebase Console ← Authentication ← Sign-in method**: فعّل "Email/Password"، ثم أضف المستخدمين (مدير، محاسب، المهندسين، مندوب المشتريات) من تبويب Users.
2. **Firestore Database**: أنشئ قاعدة بيانات (Production mode).
3. **Firestore ← Rules**: الصق محتوى ملف `firestore.rules` واضغط Publish.
4. ادخل البرنامج بحساب المدير ← **الإعدادات ← المستخدمون والصلاحيات** وأضف كل بريد بصفته. (قبل إضافة أي دور يُعامل الجميع كمديرين.)
5. **الإعدادات**: راجع بنود الأعمال وأمناء العهدة وأنواع التكلفة.
6. **المشاريع ← مشروع ← "قالب رعاية مركزة / عمليات"** لبناء شجرة البنود، ثم عدّل الجهة المنفذة والميزانية لكل بند.

## ثانيًا: الدورة اليومية
- **مهندس الموقع / المندوب**: "إدخال سريع" من الموبايل ← يرسل المشتريات أو المصروف أو العهدة ← تصل "صندوق المراجعة".
- **المحاسب**: "صندوق المراجعة" ← يراجع المشروع والبند وطريقة الدفع ← تأكيد.
- **العهد**: سجّل "استلام عهدة" باسم أمين العهدة؛ كل مصروف بطريقة دفع "عهدة" يُخصم من رصيده في "كشف العهد".
- **مقاولو الباطن**: سجّل "مستخلص" (المستحق) ثم "دفعة" عند الصرف — الرصيد المتبقي يظهر في كشف المقاولين وفي دفعة الخميس.

## ثالثًا: الأسبوعي والشهري
- **دفعة الخميس**: اختر الأسبوع ← إجمالي التكاليف بطريقة الدفع (نقدي/شيك/تحويل/عهدة)، التكلفة لكل مشروع، المستحقات المطلوب صرفها، أرصدة العهد، والحركات بلا مشروع. زر طباعة وتصدير.
- **التقارير**: فلتر تواريخ ← التكاليف حسب بند الأعمال وحسب نوع التكلفة وربحية المشاريع، مع تصدير إكسل.
- **الإعدادات ← نسخة احتياطية**: حمّل نسخة أسبوعيًا.

## الاستيراد
"استيراد إكسل" ← نزّل قالب النوع ← املأه ← ارفعه: يُقرأ مباشرة مع كشف الأخطاء. ويمكن رفع ملف إكسل قديم وتحديد الأعمدة يدويًا.

## ملاحظات مهمة
- الأساس **نقدي**: التكلفة تُسجَّل عند الصرف. "مستخلص مقاول" التزام مستحق وليس تكلفة حتى تُسجَّل دفعته.
- سلف العمال تُسجَّل عمالة عند الدفع، وكشف الأجور بصافي المنصرف بعد خصم السلف.
- تحويل عهدة بين موظفين ليس مصروفًا — لا يُسجَّل.
- قواعد الحماية (`firestore.rules`) تمنع المهندس والمندوب من قراءة الحسابات، لكنها لم تُختبر على Firebase Emulator — اختبرها بحساب تجريبي قبل الاعتماد.

## الخزائن والبنوك وكشف الخميس (الإصدار الموحّد)
- **الخزائن والبنوك**: كل حركة دفع (نقدي/شيك/تحويل) أو إيراد أو استلام عهدة تُربط بحساب، فيتحدث رصيد الخزينة/البنك تلقائيًا من الإدخال نفسه. يمكن التحويل بين الحسابات وعرض كشف حساب. الدفع من «عهدة» لا يمس الخزينة (يُخصم من رصيد أمين العهدة).
- **كشف الخميس**: يحمّل المهندس قالب الإكسل ويرفعه من شاشة الإدخال السريع مع اسم الفترة؛ يظهر للمحاسب في «صندوق المراجعة» كشفًا واحدًا (اختيار الكشف ثم «تأكيد المحدد» أو «رفض الكشف كله»).
- البيانات تُقرأ من نفس مجموعات Firebase القديمة (projects / batches / cashAccounts) فلا تضيع بياناتك السابقة.
- الاختبار الآلي: `tests/all-cases.test.js` (يحتاج Playwright وملفات تجريبية).
