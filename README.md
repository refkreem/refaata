# مقاول Pro — النظام المالي والهندسي والإداري لشركة المقاولات

صفحة واحدة `index.html` على GitHub Pages، وقاعدة بيانات Firebase (مشروع `moqawel-pro`).
الكود المصدري في `src/` ويُجمع بالأمر `./build.sh` في `index.html`.

## ترتيب القائمة
الخزائن والبنوك ← المشاريع ← مقاولو الباطن ← العمالة اليومية ← المشتريات ← الإيرادات ← مصروفات أخرى ← الأعمال المنفذة ← لوحة التحكم ← التقارير ← المراجعة والاعتماد ← الإعدادات

## فكرة النظام
1. **الخزائن والبنوك**: رصيد افتتاحي لكل حساب، إضافة/تعديل/حذف، تحويل داخلي.
2. **المشاريع**: الاسم، المدة بالشهور، بدء التنفيذ ← الاستلام الابتدائي (بدء + المدة) ← النهائي (بعد سنة)، قيمة المشروع، التكلفة المتوقعة.
3. **المقايسة** لكل مشروع (تُدخل أولًا، أو تُلصق من Excel): عند أي شراء أو مستخلص أو مصروف تُربطه ببند فيظهر فورًا: قيمة المقايسة، التكلفة المقدرة، المصروف حتى الآن، المتبقي، والكميات.
4. **مقاولو الباطن**: سجل مقاولين ← مستخلص ببنود (كمية تراكمية × فئة) ← إجمالي ← ما سبق صرفه ← دفعة مقدمة تُخصم ← استقطاعات ← الصافي ← المدفوع والمتبقي.
5. **العمالة**: يومي/شهري + سهرات + تضبيق + خصم السلف.
6. **المشتريات**: تصنيف (كهرباء/صحي/دهانات/أخرى — قابل للإضافة) وأصناف من قائمة تتسع تلقائيًا، الدفع نقدي/شيك/تحويل من أي حساب، والآجل للمورد.
7. **التقارير** (20): كشوف حسابات، ربحية، تكلفة كل بند، **المستخلص الختامي** (مقارنة كمية المقايسة بكميات الشراء والمقاولين والمنفذ والفروق والأرباح)، القيمة المكتسبة، تدفق نقدي، وغيرها — تصدير Excel وطباعة.

## الأدوار
مدير النظام، محاسب (يعتمد)، مهندس موقع (إدخال يحتاج اعتماد)، إشراف فني. تُضبط من الإعدادات ← المستخدمين (بعد إنشاء المستخدم في Firebase Authentication). قبل تعريف أي دور يدخل الجميع كمدير.

## البيانات
النظام يبدأ فارغًا. الإعدادات ← البيانات: بيانات تجريبية قابلة للحذف بزر واحد، ونسخة احتياطية JSON.
